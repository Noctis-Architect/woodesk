**WooDesk** یک برنامه‌ی دسکتاپ متن‌باز، فوق‌العاده سریع و سبک است که با **پایتون و PySide6 (Qt6)** توسعه داده شده تا مدیران سایت‌ها و فروشگاه‌های اینترنتی بتوانند بدون نیاز به لاگین مداوم در پنل سنگین وب، به صورت مستقیم از طریق REST API استاندارد، محصولات، مقالات و رسانه‌های خود را مدیریت و به کمک هوش مصنوعی متحول کنند.

---

## ✨ امکانات کلیدی / Key Features

### 🛍️ ۱. مدیریت پیشرفته محصولات ووکامرس (WooCommerce Products)
- **ویرایش سریع درون جدول (Inline Quick Edit):** امکان تغییر آنی قیمت عادی، قیمت حراج و وضعیت موجودی مستقیماً داخل جدول بدون اتلاف وقت.
- **پشتیبانی از انواع محصولات:** محصول ساده (Simple)، متغیر (Variable)، گروه‌بندی‌شده (Grouped) و خارجی/بازاریابی (External/Affiliate).
- **ویرایشگر جامع ویژگی‌ها و تنوع‌ها (Attributes & Variations):** مدیریت و اصلاح مشخصات فنی و تنوع‌های محصول به راحتی.
- **مدیریت انبار، گالری و حمل‌ونقل:** آپلود و مدیریت گالری تصاویر، تنظیم دسته‌بندی‌ها و برچسب‌ها، مدیریت وزن و ابعاد.
- **یکپارچگی با افزونه‌های سئو:** خواندن و نوشتن مستقیم متادیتای افزونه‌های مطرح **Yoast SEO** و **Rank Math**.
- **عملیات گروهی سریع (Bulk Actions):** تغییر وضعیت دسته‌جمعی، اعمال تخفیف یا افزایش قیمت درصدی/مبلغی، حذف گروهی.
- **ورود و خروج CSV:** قابلیت Import و Export سریع داده‌های محصولات.

### ✍️ ۲. مدیریت وبلاگ و نوشته‌های وردپرس (WordPress Posts)
- **ویرایشگر محتوا با پیش‌نمایش زنده:** نگارش با ویرایشگر HTML تمیز یا نگارش به زبان ساده **Markdown** با تبدیل خودکار به HTML.
- **سئو و متادیتا:** کنترل کامل عنوان، نامک (Slug)، چکیده (Excerpt)، دسته‌ها، برچسب‌ها و تصویر شاخص (Featured Image).
- **زمان‌بندی انتشار:** امکان تعیین زمان انتشار آینده یا ذخیره به عنوان پیش‌نویس (Draft).

### 🖼️ ۳. کتابخانه چندرسانه‌ای (Media Library)
- مرور و جستجوی سریع در رسانه‌های سایت.
- آپلود مستقیم فایل‌های جدید از سیستم به هاست وردپرس.
- مشاهده و ویرایش متن جایگزین (Alt Text) و جزئیات مدیا.

### 🤖 ۴. استودیو و دستیار هوش مصنوعی (AI Studio & Assistant)
- **دو حالت کاری مستقل و منعطف:**
  - **کلید اختصاصی کاربر (BYOK):** اتصال مستقیم کلاینت به هوش مصنوعی، بدون اینکه درخواستی به سمت سرور پروژه برود (حریم خصوصی ۱۰۰٪).
  - **مدل‌های رایگان سرور:** استفاده رایگان با سهمیه روزانه بدون نیاز به وارد کردن هیچ کلیدی.
- **تولید محتوای هوشمند:** نوشتن و بهبود توضیحات کامل و کوتاه محصول، نگارش مقالات تخصصی وبلاگ بر اساس کلمات کلیدی.
- **بهینه‌سازی سئو:** تولید خودکار عنوان سئو، توضیحات متا و برچسب‌های متناسب با محتوا.
- **تولید انبوه هوشمند (Bulk AI Generation):** تولید گروهی توضیحات محصولات با قابلیت مقایسه، ویرایش و تایید پیش از ذخیره‌سازی.
- **پشتیبانی از ارائه‌دهندگان مختلف:** OpenAI (GPT-4o, GPT-4o-mini), Google Gemini, Anthropic Claude, Groq, DeepSeek, Mistral, OpenRouter و مدل‌های محلی با Ollama.

### 🌐 ۵. مدیریت همزمان چند فروشگاه (Multi-Site Support)
- قابلیت افزودن نامحدود سایت وردپرسی و سوئیچ فوق‌العاده سریع بین فروشگاه‌ها بدون خروج و ورود مجدد.

### 🔒 ۶. امنیت و حریم خصوصی حداکثری
- **ذخیره‌سازی امن محلی:** کلیه کلیدها و گذرواژه‌های محرمانه در سرویس رسمی **Credential Manager ویندوز** (یا Keyring بومی سیستم) به صورت امن ذخیره می‌شوند.
- **ارتباط مستقیم و مستقل:** کلاینت دسکتاپ مستقیماً با REST API سایت شما ارتباط برقرار می‌کند و هیچ داده‌ای از فروشگاه شما (محصولات، سفارش‌ها، کاربران یا رمزها) به سرور ثالث ارسال نمی‌گردد.

### 🎨 ۷. طراحی مدرن و تجربه کاربری بومی (RTL)
- پشتیبانی کامل از حالت‌های **تیره (Dark)** و **روشن (Light)** با استایل اختصاصی.
- پشتیبانی کامل از چینش راست‌به‌چپ (RTL) همراه با قلم چشم‌نواز **وزیرمتن (Vazirmatn)**.
- رابط کاربری دوزبانه (فارسی / انگلیسی).

## 💻 نصب و اجرا / Quick Start

### ۱. پیش‌نیازها
- پایتون نسخه **3.10 یا بالاتر**
- سیستم‌عامل ویندوز ۱۰/۱۱، لینوکس یا macOS

### ۲. دریافت سورس و اجرا (ساده‌ترین روش)

```bash
# دریافت مخزن
git clone https://github.com/Noctis-Architect/woodesk.git
cd woodesk

# یک دستور برای ساخت محیط مجازی، نصب همه پیش‌نیازها و اجرای برنامه:
bash run.sh          # لینوکس / مک
run.bat              # ویندوز
```

اسکریپت‌های بالا به‌صورت خودکار یک محیط مجازی (`.venv`) می‌سازند، همه‌ی کتابخانه‌ها را نصب می‌کنند و برنامه را اجرا می‌کنند. این روش روی توزیع‌هایی مثل دبیان/اوبونتو که نصب سراسری `pip` را محدود می‌کنند (PEP 668) هم بدون مشکل کار می‌کند.

<details>
<summary>نصب دستی (اختیاری)</summary>

```bash
python -m venv .venv

# فعال‌سازی محیط مجازی:
# در ویندوز:
.venv\Scripts\activate
# در لینوکس یا مک:
source .venv/bin/activate

# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرا
python run.py
```

> نکته: روی دبیان/اوبونتو نصب `pip install` به‌صورت سراسری خطای `externally-managed-environment` می‌دهد؛ همیشه از محیط مجازی (`venv`) استفاده کنید.
</details>

### ۳. اجرا به‌صورت برنامه‌ی آماده (بدون نیاز به پایتون)

فایل‌های اجرایی آماده‌ای که در بخش [Releases](https://github.com/Noctis-Architect/woodesk/releases) قرار می‌گیرند، **تمام پیش‌نیازها را در خود دارند** و نیازی به نصب پایتون یا هیچ کتابخانه‌ای ندارند. برای ساخت آن به بخش [ساخت نسخه و بیلد](#-ساخت-نسخه-و-بیلد) مراجعه کنید.

## 🔌 نحوه اتصال به فروشگاه و وردپرس

پس از باز شدن برنامه، به بخش **تنظیمات (Settings) > سایت‌ها (Sites) > افزودن سایت (Add Site)** بروید:

1. **آدرس سایت:** نشانی کامل سایت به همراه پروتکل (مثال: `https://myshop.com`).
2. **احراز هویت وردپرس:**
   - **نام کاربری** وردپرس
   - **رمز عبور کاربردی (Application Password):** در پیشخوان وردپرس > کاربران > شناسنامه شما > بخش «رمزهای عبور کاربردی»، یک نام انتخاب کرده و روی «افزودن رمز عبور کاربردی جدید» کلیک کنید و رشته‌ی تولیدشده را اینجا وارد کنید.
3. **احراز هویت ووکامرس:**
   - در پیشخوان وردپرس > ووکامرس > پیکربندی > پیشرفته > REST API > افزودن کلید:
   - سطح دسترسی را روی **«خواندن/نوشتن» (Read/Write)** بگذارید و **Consumer Key** و **Consumer Secret** را کپی و در برنامه وارد نمایید.
   - *(نکته: در صورتی که سایت شما از HTTPS استفاده می‌کند، می‌توانید با همان Application Password نیز دسترسی ووکامرس را برقرار کنید).*

## 🧠 حالت‌های هوش مصنوعی (AI Modes)

بخش هوش مصنوعی در WooDesk برای سازگاری با نیازهای مختلف و تضمین حریم خصوصی، به **دو حالت مجزا** مجهز شده است که می‌توانید در منوی **تنظیمات (Settings) > هوش مصنوعی (AI)** به دلخواه انتخاب کنید:

| ویژگی | حالت ۱: کلید اختصاصی کاربر (BYOK) | حالت ۲: مدل‌های رایگان سرور پروژه |
| :--- | :--- | :--- |
| **هزینه / کلید** | کلید API خودتان یا مدل لوکال (رایگان) | ۱۰۰٪ رایگان و بدون نیاز به ثبت هیچ کلیدی |
| **مسیر ارسال درخواست** | **مستقیم به هوش مصنوعی** (سمت سرور پروژه هیچی نمی‌آید) | از طریق سرور پروژه با اعمال سهمیه روزانه |
| **حریم خصوصی** | **کامل و مستقل** (ارتباط مستقیم کلاینت با پرووایدر) | امن (بدون ارسال داده‌های محرمانه فروشگاه) |
| **سقف و محدودیت** | تابع اکانت شخصی خودتان (نامحدود در مدل لوکال) | سهمیه روزانه مشخص برای هر نصب |
| **مدل‌های قابل استفاده** | کلیه مدل‌های OpenAI، Gemini، Claude، Groq، DeepSeek، Ollama و ... | مدل‌های بهینه‌شده تعیین‌شده روی سرور (مثل GPT-4o-mini) |

---

### ۱. حالت کلید اختصاصی خودتان (Custom API Key / BYOK)
- **ارتباط مستقیم و حریم خصوصی ۱۰۰٪:** در این حالت، شما کلید API ارائه‌دهنده‌ی دلخواه خود را وارد می‌کنید. تمام درخواست‌ها **مستقیماً از کلاینت روی سیستم شما به سرور سرویس‌دهنده (مانند OpenAI یا Google)** ارسال می‌شوند و **هیچ درخواستی به سمت سرور پروژه ارسال نمی‌شود**.
- **ذخیره‌سازی امن محلی:** کلیدهای واردشده تنها در حافظه امن ویندوز (**Windows Credential Manager**) یا Keyring بومی سیستم‌عامل شما به شکل رمزنگاری‌شده نگهداری می‌شوند و هرگز در هیچ فایل متنی ساده ذخیره نمی‌گردند.
- **پشتیبانی از مدل‌های آفلاین و محلی (Local AI):** با ابزارهایی مانند **Ollama** یا **LM Studio** می‌توانید مدل‌های رایگان متن‌باز (مانند Llama 3، DeepSeek یا Mistral) را روی سیستم شخصی خود اجرا کنید و در WooDesk به صورت کاملاً آفلاین، نامحدود و بدون نیاز به اینترنت و بدون پرداخت هزینه استفاده نمایید.

---

### ۲. حالت استفاده از مدل‌های رایگان سرور پروژه (Free Server Models)
- **شروع سریع بدون نیاز به کلید:** برای کاربرانی طراحی شده که کلید اختصاصی ندارند یا می‌خواهند امکانات تولید محتوای هوش مصنوعی را بلافاصله و بدون هزینه آزمایش کنند.
- **مدل‌های آماده با سهمیه روزانه:** در این حالت، درخواست‌ها به سرور پروژه هدایت شده و از مدل‌های رایگانی که روی سرور فعال شده‌اند (با سقف درخواست و توکن روزانه) استفاده می‌شود.
- **مشاهده سهمیه:** کافیست در تب هوش مصنوعی روی دکمه‌ی «بروزرسانی مدل‌ها و سهمیه» کلیک کنید تا مدل فعال و تعداد درخواست‌های باقیمانده‌ی امروز به شما نشان داده شود.

## 🧪 تست بدون نیاز به فروشگاه واقعی (Mock Store)

برای تست و بررسی امکانات بدون اتصال به یک سایت زنده، یک شبیه‌ساز سریع فروشگاه و وردپرس همراه پروژه قرار داده شده است:
```bash
# اجرای فروشگاه مجازی بر روی http://127.0.0.1:8099
python -m dev.fake_store
```
سپس در برنامه یک سایت با آدرس `http://127.0.0.1:8099` و اطلاعات دلخواه اضافه کنید.

## 🏗️ ساخت نسخه و بیلد

برای ساخت فایل اجرایی و فایل نصبی، **همه‌ی پیش‌نیازها (مفسر پایتون، PySide6/Qt، کتابخانه‌ها، فونت‌ها، لوگو و ماژول‌های داینامیک) به‌صورت خودکار در بیلد قرار می‌گیرند** و کاربر نهایی نیازی به نصب پایتون یا هیچ کتابخانه‌ای ندارد. بیلد با **PyInstaller** انجام می‌شود:

```powershell
# ویندوز: فایل اجرایی + اینستالر (نیازمند Inno Setup برای ساخت Setup)
powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1
```

```bash
# لینوکس: پوشه‌ی قابل اجرا + فایل فشرده
bash packaging/build_linux.sh
```

خروجی‌ها:
- ویندوز: `dist\WooDesk\WooDesk.exe` و (در صورت نصب Inno Setup) `dist\WooDesk-Setup.exe`
- لینوکس: `dist/WooDesk/WooDesk` و `dist/WooDesk-linux.tar.gz`

همچنین با ایجاد تگ نسخه (مانند `v1.0.0`) و پوش به گیت‌هاب، گیت‌هاب اکشنز پروژه به صورت خودکار نسخه‌های ویندوز و لینوکس را کامپایل کرده و در بخش Releases قرار می‌دهد.

## 📂 ساختار پروژه

```text
woodesk/
├── app/                  # هسته و رابط کاربری کلاینت دسکتاپ
│   ├── ai/               # مدیریت کلاینت‌های هوش مصنوعی و پرامپت‌ها
│   ├── api/              # کلاینت‌های HTTP وردپرس و ووکامرس
│   ├── assets/           # فونت‌ها، استایل‌ها و لوگوی رسمی ووکامرس (branding/)
│   ├── core/             # تنظیمات، مدیریت رمزشده Secretها، رشته‌های دوزبانه
│   ├── resources.py      # مسیردهی به منابع در حالت سورس و بیلدشده
│   └── ui/               # صفحات و کامپوننت‌های PySide6 (محصولات، مقالات، تنظیمات و ...)
├── dev/                  # ابزارهای توسعه، فروشگاه شبیه‌سازی‌شده (Fake Store) و تست UI
├── modules/              # ماژول‌های داینامیک با قابلیت بروزرسانی داغ (remote_service)
├── packaging/            # اسکریپت‌های بیلد PyInstaller، فایل spec و فایل سورس Inno Setup
├── tests/                # تست‌های خودکار پروژه (pytest)
├── requirements.txt      # پیش‌نیازهای اجرای برنامه
├── requirements-dev.txt  # وابستگی‌های محیط توسعه و تست
├── run.sh / run.bat      # نصب خودکار پیش‌نیازها و اجرا (لینوکس‌/‌مک و ویندوز)
└── run.py                # نقطه ورود اجرای برنامه
```
