# WooDesk — مدیریت دسکتاپ ووکامرس و وردپرس با هوش مصنوعی

برنامه‌ی ویندوزی (و لینوکس/مک) متن‌باز، با پایتون و PySide6، برای مدیریت کامل **محصولات** و **مقالات** فروشگاه‌های وردپرس/ووکامرس از طریق REST API.
Open-source desktop manager for WooCommerce products & WordPress posts, with built-in AI.

## امکانات / Features
- **محصولات:** جدول با جستجو/فیلتر/صفحه‌بندی، ویرایش سریع قیمت و موجودی داخل جدول، ویرایشگر کامل (ساده/متغیر/گروهی/خارجی، تنوع‌ها، تصاویر، دسته/برچسب، موجودی، ارسال، سئو Yoast/RankMath)، عملیات گروهی (وضعیت، تغییر قیمت درصدی/مبلغی، حذف)، ورود/خروج CSV.
- **مقالات:** ویرایشگر HTML با پیش‌نمایش، Markdown→HTML، دسته/برچسب، تصویر شاخص، زمان‌بندی انتشار.
- **رسانه:** آپلود، جستجو، متن جایگزین، حذف.
- **هوش مصنوعی:** نوشتن/بهبود/ترجمه‌ی توضیحات، سئو، برچسب، مقاله‌ی کامل، تولید گروهی توضیحات با بازبینی قبل از اعمال. دو حالت: کلید و Base URL خودتان (OpenAI، OpenRouter، Gemini، Groq، DeepSeek، Mistral، Anthropic، Ollama، …) یا **مدل رایگان سرور پروژه** با سهمیه‌ی روزانه.
- **چند سایت**، تم روشن/تیره، فارسی (RTL) و انگلیسی، ذخیره‌ی امن رمزها در Credential Manager ویندوز.
- **سرور (اختیاری):** پروکسی AI رایگان با سهمیه، آمار ناشناس نصب‌ها و دامنه‌ها، ارسال اعلان به همه‌ی نصب‌ها، پنل ادمین.

## اجرا / Run
```bash
pip install -r requirements.txt
python run.py
```
در برنامه: **تنظیمات > سایت‌ها > افزودن سایت**
- آدرس سایت + نام‌کاربری وردپرس + *Application Password* (پروفایل کاربر در وردپرس)
- ووکامرس: *Consumer Key/Secret* (ووکامرس > تنظیمات > پیشرفته > REST API) یا همان Application Password (فقط HTTPS).

> برای تست بدون فروشگاه واقعی: `python -m dev.fake_store` یک وردپرس/ووکامرس و API هوش مصنوعی جعلی روی `127.0.0.1:8099` بالا می‌آورد.

## سرور / Server
```bash
cd server
cp .env.example .env     # ADMIN_TOKEN, SERVER_SALT, کلید(های) AI را پر کنید
docker compose up -d --build
```
- پشت یک reverse proxy با HTTPS قرار دهید (Caddy/nginx) و `TRUST_PROXY=true` بماند.
- پنل ادمین: `https://YOUR-SERVER/admin` (با `ADMIN_TOKEN`): آمار، سایت‌های متصل، ارسال اعلان، سهمیه و روشن/خاموش کردن مدل رایگان.
- آدرس سرور را موقع بیلد با `WOODESK_SERVER_URL` در برنامه قرار دهید (کاربر هم می‌تواند در تنظیمات تغییر دهد).

### امنیت مدل رایگان
کلید AI شما **فقط روی سرور** است و داخل برنامه نیست. سهمیه سمت سرور (به ازای نصب + IP + نرخ در دقیقه) اعمال می‌شود، مدل و سقف توکن را سرور تعیین می‌کند و درخواست ناموفق از سهمیه کم نمی‌شود.

## حریم خصوصی / Privacy
آمار به‌صورت پیش‌فرض فعال است و کاربر می‌تواند در **تنظیمات > سرور و حریم خصوصی** خاموشش کند (و با خاموش کردن، لیست سایت‌ها از سرور هم پاک می‌شود). در اولین اجرا یک اطلاعیه نمایش داده می‌شود. فقط این‌ها ارسال می‌شود: شناسه‌ی تصادفی نصب، نسخه‌ی برنامه، سیستم‌عامل، زبان، **نام دامنه‌ی** سایت‌های افزوده‌شده. هرگز رمز، کلید، محصول، مقاله، مشتری یا سفارش ارسال نمی‌شود. دکمه‌ی «نمایش داده‌هایی که ارسال می‌شود» همان JSON را نشان می‌دهد. سرور IP را فقط به‌صورت hash (برای ضدسوءاستفاده) نگه می‌دارد.
