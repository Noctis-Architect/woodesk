**WooDesk** یک برنامه‌ی دسکتاپ متن‌باز، فوق‌العاده سریع و سبک است که با **پایتون و PySide6 (Qt6)** توسعه داده شده تا مدیران سایت‌ها و فروشگاه‌های اینترنتی بتوانند بدون نیاز به لاگین مداوم در پنل سنگین وب، به صورت مستقیم از طریق REST API استاندارد، محصولات، مقالات و رسانه‌های خود را مدیریت و به کمک هوش مصنوعی متحول کنند.

---

## ✨ امکانات کلیدی / Key Features

### 🛍️ ۱. مدیریت پیشرفته محصولات ووکامرس (WooCommerce Products)
- **ویرایش سریع درون جدول (Inline Quick Edit):** امکان تغییر آنی قیمت عادی، قیمت حراج و وضعیت موجودی مستقیماً داخل جدول بدون اتلاف وقت.
- **پشتیبانی از انواع محصولات:** محصول ساده (Simple)، متغیر (Variable)، گروه‌بندی‌شده (Grouped) و خارجی/بازاریابی (External/Affiliate).
- **ویرایشگر جامع ویژگی‌ها و تنوع‌ها (Attributes & Variations):** مدیریت و اصلاح مشخصات فنی و تنوع‌های محصول به راحتی.
- **مدیریت انبار، گالری و حمل‌ونقل:** آپلود و مدیریت گالری تصاویر، تنظیم دسته‌بندی‌ها و برچسب‌ها، مدیریت وزن و ابعاد.
- **یکپارچگی با افزونه‌های سئو:** خواندن و نوشتن مستقیم متادیتای افزونه‌های مطرح **Yoast SEO** و **Rank Math**.
- **عملیات گروهی سریع (Bulk Actions):** تغییر وضعیت دسته‌جمعی، اعمال تخفیف یا افزایش قیمت درصدی/مبلغی، حذف گروهی.
- **ورود و خروج CSV:** قابلیت Import و Export سریع داده‌های محصولات.

### ✍️ ۲. مدیریت وبلاگ و نوشته‌های وردپرس (WordPress Posts)
- **ویرایشگر محتوا با پیش‌نمایش زنده:** نگارش با ویرایشگر HTML تمیز یا نگارش به زبان ساده **Markdown** با تبدیل خودکار به HTML.
- **سئو و متادیتا:** کنترل کامل عنوان، نامک (Slug)، چکیده (Excerpt)، دسته‌ها، برچسب‌ها و تصویر شاخص (Featured Image).
- **زمان‌بندی انتشار:** امکان تعیین زمان انتشار آینده یا ذخیره به عنوان پیش‌نویس (Draft).

### 🖼️ ۳. کتابخانه چندرسانه‌ای (Media Library)
- مرور و جستجوی سریع در رسانه‌های سایت.
- آپلود مستقیم فایل‌های جدید از سیستم به هاست وردپرس.
- مشاهده و ویرایش متن جایگزین (Alt Text) و جزئیات مدیا.

### 🤖 ۴. استودیو و دستیار هوش مصنوعی (AI Studio & Assistant)
- **تولید محتوای هوشمند:** نوشتن و بهبود توضیحات کامل و کوتاه محصول، نگارش مقالات تخصصی وبلاگ بر اساس کلمات کلیدی.
- **بهینه‌سازی سئو:** تولید خودکار عنوان سئو، توضیحات متا و برچسب‌های متناسب با محتوا.
- **تولید انبوه هوشمند (Bulk AI Generation):** تولید گروهی توضیحات محصولات با قابلیت مقایسه، ویرایش و تایید پیش از ذخیره‌سازی.
- **مدل دلخواه با کلید شخصی (BYOK):** اتصال مستقیم به انواع ارائه‌دهندگان هوش مصنوعی:
  - **OpenAI** (GPT-4o, GPT-4o-mini و ...)
  - **Google Gemini**
  - **Anthropic Claude**
  - **Groq**, **DeepSeek**, **Mistral**, **OpenRouter**
  - **مدل‌های محلی (Local AI):** اتصال از طریق **Ollama** یا LM Studio روی سیستم خودتان
  - یا هر سرور پروکسی سازگار با استاندارد OpenAI.

### 🌐 ۵. مدیریت همزمان چند فروشگاه (Multi-Site Support)
- قابلیت افزودن نامحدود سایت وردپرسی و سوئیچ فوق‌العاده سریع بین فروشگاه‌ها بدون خروج و ورود مجدد.

### 🔒 ۶. امنیت و حریم خصوصی حداکثری
- **ذخیره‌سازی امن محلی:** کلیه کلیدها و گذرواژه‌های محرمانه در سرویس رسمی **Credential Manager ویندوز** (یا Keyring بومی سیستم) به صورت امن ذخیره می‌شوند.
- **ارتباط مستقیم و مستقل:** کلاینت دسکتاپ مستقیماً با REST API سایت شما ارتباط برقرار می‌کند و هیچ داده‌ای از فروشگاه شما (محصولات، سفارش‌ها، کاربران یا رمزها) به سرور ثالث ارسال نمی‌گردد.

### 🎨 ۷. طراحی مدرن و تجربه کاربری بومی (RTL)
- پشتیبانی کامل از حالت‌های **تیره (Dark)** و **روشن (Light)** با استایل اختصاصی.
- پشتیبانی کامل از چینش راست‌به‌چپ (RTL) همراه با قلم چشم‌نواز **وزیرمتن (Vazirmatn)**.
- رابط کاربری دوزبانه (فارسی / انگلیسی).

## 💻 نصب و اجرا / Quick Start

### ۱. پیش‌نیازها
- پایتون نسخه **3.10 یا بالاتر**
- سیستم‌عامل ویندوز ۱۰/۱۱، لینوکس یا macOS

### ۲. دریافت سورس و نصب کتابخانه‌ها
```bash
# دریافت مخزن
git clone https://github.com/Noctis-Architect/woodesk.git
cd woodesk

# ایجاد محیط مجازی (پیشنهادی)
python -m venv .venv

# فعال‌سازی محیط مجازی:
# در ویندوز:
.venv\Scripts\activate
# در لینوکس یا مک:
source .venv/bin/activate

# نصب وابستگی‌ها
pip install -r requirements.txt
```

### ۳. اجرای برنامه
```bash
python run.py
```

## 🔌 نحوه اتصال به فروشگاه و وردپرس

پس از باز شدن برنامه، به بخش **تنظیمات (Settings) > سایت‌ها (Sites) > افزودن سایت (Add Site)** بروید:

1. **آدرس سایت:** نشانی کامل سایت به همراه پروتکل (مثال: `https://myshop.com`).
2. **احراز هویت وردپرس:**
   - **نام کاربری** وردپرس
   - **رمز عبور کاربردی (Application Password):** در پیشخوان وردپرس > کاربران > شناسنامه شما > بخش «رمزهای عبور کاربردی»، یک نام انتخاب کرده و روی «افزودن رمز عبور کاربردی جدید» کلیک کنید و رشته‌ی تولیدشده را اینجا وارد کنید.
3. **احراز هویت ووکامرس:**
   - در پیشخوان وردپرس > ووکامرس > پیکربندی > پیشرفته > REST API > افزودن کلید:
   - سطح دسترسی را روی **«خواندن/نوشتن» (Read/Write)** بگذارید و **Consumer Key** و **Consumer Secret** را کپی و در برنامه وارد نمایید.
   - *(نکته: در صورتی که سایت شما از HTTPS استفاده می‌کند، می‌توانید با همان Application Password نیز دسترسی ووکامرس را برقرار کنید).*

## 🧪 تست بدون نیاز به فروشگاه واقعی (Mock Store)

برای تست و بررسی امکانات بدون اتصال به یک سایت زنده، یک شبیه‌ساز سریع فروشگاه و وردپرس همراه پروژه قرار داده شده است:
```bash
# اجرای فروشگاه مجازی بر روی http://127.0.0.1:8099
python -m dev.fake_store
```
سپس در برنامه یک سایت با آدرس `http://127.0.0.1:8099` و اطلاعات دلخواه اضافه کنید.

## 🏗️ ساخت نسخه ویندوز و بیلد

برای ساخت فایل اجرایی (`.exe`) و فایل نصبی ویندوز:
```powershell
# ساخت فایل اجرایی با PyInstaller
powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1

# کامپایل فایل نصبی اینستالر (نیازمند Inno Setup)
# فایل packaging\installer.iss را باز کرده و Compile را بزنید
```
همچنین با ایجاد تگ نسخه (مانند `v1.0.0`) و پوش به گیت‌هاب، گیت‌هاب اکشنز پروژه به صورت خودکار نسخه Zip آماده اجرا را کامپایل کرده و در بخش Releases قرار می‌دهد.

## 📂 ساختار پروژه

```text
woodesk/
├── app/                  # هسته و رابط کاربری کلاینت دسکتاپ
│   ├── ai/               # مدیریت کلاینت‌های هوش مصنوعی و پرامپت‌ها
│   ├── api/              # کلاینت‌های HTTP وردپرس و ووکامرس
│   ├── assets/           # فونت‌های Vazirmatn و استایل‌ها
│   ├── core/             # تنظیمات، مدیریت رمزشده Secretها، رشته‌های دوزبانه
│   └── ui/               # صفحات و کامپوننت‌های PySide6 (محصولات، مقالات، تنظیمات و ...)
├── dev/                  # ابزارهای توسعه، فروشگاه شبیه‌سازی‌شده (Fake Store) و تست UI
├── packaging/            # اسکریپت‌های بیلد PyInstaller و فایل سورس Inno Setup
├── tests/                # تست‌های خودکار پروژه (pytest)
├── requirements.txt      # پیش‌نیازهای اجرای برنامه
├── requirements-dev.txt  # وابستگی‌های محیط توسعه و تست
└── run.py                # نقطه ورود اجرای برنامه
```
